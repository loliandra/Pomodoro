# 🍅 Pomodoro Timer — Tkinter Productivity App

A simple desktop Pomodoro Timer built with Python and Tkinter.

This project helps improve focus and productivity using the famous **Pomodoro Technique**, where work sessions are split into timed intervals followed by breaks.

The application provides a clean graphical interface with session tracking and automatic timer switching.

---

##  Features

✅ Work session timer  
✅ Short break timer  
✅ Long break timer after multiple sessions  
✅ Automatic session switching  
✅ Visual session checkmarks  
✅ Reset timer functionality  
✅ Simple and minimal GUI  

---

##  Pomodoro Logic

The timer follows this cycle:

- 25 minutes work  
- 25 minutes short break  
- After 4 work sessions → 20 minutes long break  

Session progress is displayed using ✔ checkmarks.

---

##  UI Preview

The interface includes:

- Timer label  
- Tomato themed countdown canvas  
- Start button  
- Reset button  
- Session progress indicator
